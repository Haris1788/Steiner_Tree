3. Direction 1 — Lower Bound: OPT(I') ≤ OPT(I)

Why OPT(I') ≤ OPT(I)?

For any edge (u, v) ∈ E of graph G, its cost in G' is at most its cost in G, because the edge itself is one candidate shortest path.

∴ cost'(u,v) ≤ cost(u,v) for every edge (u,v) ∈ E

∴ The optimal Steiner tree of G can be placed into G' with equal or lower total cost.

$$OPT(I') \leq OPT(I)$$

5. Conclusion — Factor-Preserving Reduction

The Reduction: I → I' → T' → T

StepInputOutputOperationTime
1 Instance I (Graph G) Instance I' (Graph G') Compute metric closure (all-pairs shortest paths) Polynomial
2 Instance I' (Metric Graph G') Approx Tree T' Run α-approximation algorithm for metric Steiner tree Depends on alg.
3 Tree T' in G' Tree T in G Replace edges by shortest paths, remove duplicates/cycles Polynomial

The Chain of Inequalities

cost(T)
    ≤   cost'(T')     (mapping back: replacing edges by paths can only reduce cost)
    ≤   α · OPT(I')     (T' is an α-approximation in G')
    ≤   α · OPT(I)     (lower bound: OPT(I') ≤ OPT(I))

$$\text{cost}(T) \;\leq\; \text{cost}'(T') \;\leq\; \alpha \cdot OPT(I') \;\leq\; \alpha \cdot OPT(I)$$

Theorem 3.2 (Vazirani)

Statement: The reduction from the Steiner tree problem to the metric Steiner tree problem is approximation factor preserving.

Consequence: Any approximation factor established for the metric Steiner tree problem carries over to the general Steiner tree problem.

If there exists an α-approximation algorithm for the metric Steiner tree problem,
then there exists an α-approximation algorithm for the general Steiner tree problem.  ■
